# KHI004: void* without a stated reason

| Item | Value |
| :-- | :-- |
| Category | Interop |
| Severity | Error |
| Analyzer | `KappaDuck.Khaos.Internal.Analyzers` |

## Cause

A method in an interop area takes or returns `void*` at any level of
indirection and does not carry `[UntypedPointer]` with a non-empty reason.

## Why

`void*` is the right answer when the native side is genuinely untyped, and the
wrong answer when the real type is simply unknown. The two look identical in
the source. A written reason separates them: a `userdata` pointer SDL hands back
untouched has one, a handle nobody looked up on the wiki does not.

The reason is an attribute rather than a comment so that it survives a reformat,
can be found by searching, and cannot be satisfied by typing `// void*`.

It sits on the method rather than on the parameter because that is where the
decision was made, and because one sentence usually covers the whole signature.

## Reported

```csharp
namespace KappaDuck.Khaos.Interop.SDL;

internal static unsafe partial class SDL3
{
    [LibraryImport(nameof(SDL3), EntryPoint = "SDL_SetEventFilter")]
    internal static partial void SetEventFilter(void* userdata);
    //                           ~~~~~~~~~~~~~~ KHI004: 'SetEventFilter' takes or returns void*
    //                                          without [UntypedPointer]; say why it cannot be typed
}
```

An empty or whitespace reason is not a reason, and is reported the same way.

## Fix

```csharp
[LibraryImport(nameof(SDL3), EntryPoint = "SDL_SetEventFilter")]
[UntypedPointer("SDL hands userdata back to the filter untouched and never reads it")]
internal static partial void SetEventFilter(void* userdata);
```

If no such sentence can be written, the pointer has a type and it has not been
looked up yet. That is the case the rule exists for.

## Not reported

- **A typed pointer.** `SDL_Window*` says what it carries.
- **A `void*` field.** The attribute targets methods; a struct that stores
  untyped memory documents it where the struct is declared.
- **A `void*` outside `Interop/SDL` and `Interop/Win32`.**
- **The generated implementing half of a partial method.**

## Suppressing

Never. The suppression would take more characters than the reason.
