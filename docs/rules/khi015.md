# KHI015: event case has no valid native constructor

| Item     | Value                                |
| :------- | :----------------------------------- |
| Category | Events                               |
| Severity | Error                                |
| Analyzer | `KappaDuck.Khaos.Internal.Analyzers` |

## Cause

A `[KhaosEvent]` case breaks the contract of its native constructor:

- it has a payload, but no constructor besides its positional one;
- it declares more than one constructor besides its positional one;
- its native constructor is not `internal`;
- its first parameter is not taken by `in`, or its type is not the type of exactly one field of `SDL_Event`;
- its second parameter is not `in EventContext`.

A case with no payload, such as `QuitRequested`, needs no constructor.

## Why

The generated `EventConverter` turns the `SDL_Event` that SDL hands to `SDL_AppEvent` into `Event`. For each
case it writes one line:

```csharp
case SDL_EventType.WindowResized:
    e = new Event(new WindowResized(in native.Window, in context));
    return true;
```

It finds `native.Window` by the type of the constructor's first parameter: `SDL_WindowEvent` is the type of one
field of `SDL_Event` only. It adds `in context` when the constructor asks for an `EventContext`, which carries what
the native event does not say, such as the content scale that turns a size into logical units.

The constructor stays `internal`: it takes interop types, which never leak into the public API.

## Reported

```csharp
[KhaosEvent(SDL_EventType.KeyDown)]
public readonly record struct KeyPressed(Scancode Code);
//                            ~~~~~~~~~~ KHI015: 'KeyPressed' has a payload but no internal constructor
//                                       that takes its native event
```

## Fix

```csharp
[KhaosEvent(SDL_EventType.KeyDown)]
public readonly record struct KeyPressed(Scancode Code)
{
    internal KeyPressed(in SDL_KeyboardEvent native)
        : this((Scancode)native.Scancode)
    {
    }
}
```

A case that needs the engine's state takes the context too:

```csharp
internal WindowResized(in SDL_WindowEvent native, in EventContext context)
    : this(WindowScale.ToLogical(new SizeI(native.Data1, native.Data2), context.ContentScale))
{
}
```

## Suppressing

Never. The generator leaves the case out of `Event`, so the game never receives it.
