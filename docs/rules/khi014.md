# KHI014: event case holds a reference other than a string

| Item     | Value                                |
| :------- | :----------------------------------- |
| Category | Events                               |
| Severity | Error                                |
| Analyzer | `KappaDuck.Khaos.Internal.Analyzers` |

## Cause

A `[KhaosEvent]` case has an instance field, or an auto-property, whose type is neither unmanaged nor `string`:
an array, a list, a class.

## Why

`Event` keeps its unmanaged cases in the same bytes, in a nested struct with `LayoutKind.Explicit`, so its size
is the size of the largest case and not their sum. The runtime refuses a reference in that overlap: "offsets
occupied by an object reference shall not overlap with offsets occupied by a built-in value type or a part of
another object reference" ([ECMA-335 II.10.7]).

A case that holds a `string` gets a field of its own beside the overlap: text input needs it. Every other
reference is refused. It would grow `Event` by one field per case, and it would hand the game an object that SDL
filled once and that the game can keep alive by mistake.

## Reported

```csharp
[KhaosEvent(SDL_EventType.DropFile)]
public readonly record struct FilesDropped(List<string> Paths)
//                            ~~~~~~~~~~~~ KHI014: 'FilesDropped' holds 'Paths' of type
//                                         System.Collections.Generic.List<string>; an event case holds only
//                                         unmanaged values and strings
```

## Fix

Send one event per item, and let the game collect them:

```csharp
[KhaosEvent(SDL_EventType.DropFile)]
public readonly record struct FileDropped(string Path)
{
    internal FileDropped(in SDL_DropEvent native)
        : this(native.ReadPath())
    {
    }
}
```

## Not reported

- **Unmanaged fields**: numbers, enums, `bool`, and structs made only of them, such as `SizeI`.
- **`string` fields.**
- **Static and `const` fields.**

## Suppressing

Never. The generator leaves the case out of `Event`, so the game never receives it.

[ECMA-335 II.10.7]: https://github.com/stakx/ecma-335/blob/master/docs/ii.10.7-controlling-instance-layout.md
