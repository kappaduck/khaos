# KHI013: event case is not a public readonly record struct

| Item     | Value                                |
| :------- | :----------------------------------- |
| Category | Events                               |
| Severity | Error                                |
| Analyzer | `KappaDuck.Khaos.Internal.Analyzers` |

## Cause

A type marked `[KhaosEvent]` is not a `public`, non-generic, top-level `readonly record struct`, or its attribute
names a range whose last native type comes before its first.

## Why

The event union generator copies every case into `Event`, a struct that a game receives by `in` in `OnEvent` and
reads with patterns such as `e is KeyPressed { Code: Scancode.Escape }`.

- **A struct**, because `Event` stores its cases inline, with no allocation.
- **`readonly`**, because `OnEvent` receives the event by `in`: a mutable case would be copied before every
  member call ([readonly struct]).
- **A `record`**, because a game compares and prints events, and a record writes `Equals` and `ToString` itself.
- **`public`**, because the generated constructors of `Event` are public, and the compiler only treats a
  constructor's parameter type as a case of the union when the constructor is public ([union types]).
- **Not generic, not nested**, because each case gets one constructor and one `TryGetValue` on `Event`, named
  after the type.

A range such as `[KhaosEvent(SDL_EventType.User, SDL_EventType.Last)]` becomes a relational pattern in the
converter. A range that ends before it starts matches nothing.

The generator leaves such a case out of `Event` without a word; this rule says why.

## Reported

```csharp
[KhaosEvent(SDL_EventType.KeyUp)]
public record struct KeyReleased;
//                   ~~~~~~~~~~~ KHI013: 'KeyReleased' is marked [KhaosEvent]; declare it as a public,
//                               non-generic, top-level readonly record struct

[KhaosEvent(SDL_EventType.Last, SDL_EventType.User)]
public readonly record struct Backwards;
//                            ~~~~~~~~~ KHI013: 'Backwards' covers a range of native types whose last
//                                      type comes before its first
```

## Fix

```csharp
[KhaosEvent(SDL_EventType.KeyUp)]
public readonly record struct KeyReleased(Scancode Code)
{
    internal KeyReleased(in SDL_KeyboardEvent native)
        : this((Scancode)native.Scancode)
    {
    }
}
```

## Suppressing

Never. A case of another shape is not in `Event`, so the game never receives it.

[union types]: https://learn.microsoft.com/dotnet/csharp/language-reference/builtin-types/union
