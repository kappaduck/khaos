# KHI001: bool does not follow the marshalling convention of its interop area

| Item | Value |
| :-- | :-- |
| Category | Interop |
| Severity | Error |
| Analyzer | `KappaDuck.Khaos.Internal.Analyzers` |

## Cause

A `bool` crosses the native boundary without the marshalling convention of the
interop area it lives in. Reported on the return value and the parameters of a
`[LibraryImport]` method.

| Area | Native type | Required |
| :-- | :-- | :-- |
| `KappaDuck.Khaos.Interop.SDL` | `bool` (C99, 1 byte) | `UnmanagedType.U1` |
| `KappaDuck.Khaos.Interop.Win32` | `BOOL` (`typedef int`, 4 bytes) | `UnmanagedType.Bool` |

The area is the folder directly under `Interop/`, which the namespace mirrors.

Struct fields are **not** covered by this rule. See [KHI007](khi007.md).

## Why

Runtime marshalling stays enabled in Khaos, and its default for `bool` is the
4-byte Win32 `BOOL`. That default is right for `Interop/Win32` and wrong for
`Interop/SDL`, so the same missing attribute is harmless on one side and silent
memory corruption on the other. `UnmanagedType.U1` on a Win32 binding is the
same bug in reverse: it reads one byte of a four-byte value.

Neither case fails loudly. The value is simply wrong, sometimes.

`UnmanagedType.Bool` is already the runtime default and is written anyway. A
reader cannot tell a deliberate 4-byte `BOOL` from a `bool` nobody thought
about, and this rule is the place that difference gets decided.

## Reported

Return value:

```csharp
namespace KappaDuck.Khaos.Interop.SDL;

internal static unsafe partial class SDL3
{
    [LibraryImport(nameof(SDL3), EntryPoint = "SDL_HasClipboardText")]
    internal static partial bool HasClipboardText();
    //                   ~~~~ KHI001: The return value of 'HasClipboardText' does not follow
    //                        the SDL bool convention; expected [return: MarshalAs(UnmanagedType.U1)]
}
```

Parameter:

```csharp
[LibraryImport(nameof(SDL3), EntryPoint = "SDL_SetGamepadEventsEnabled")]
internal static partial void SetGamepadEventsEnabled(bool enabled);
//                                                   ~~~~ KHI001: Parameter 'enabled' of
//                                                        'SetGamepadEventsEnabled' does not follow
//                                                        the SDL bool convention;
//                                                        expected [MarshalAs(UnmanagedType.U1)]
```

Reversed, on the Win32 side:

```csharp
namespace KappaDuck.Khaos.Interop.Win32;

internal static unsafe partial class User32
{
    [LibraryImport("user32", EntryPoint = "ShowCursor")]
    internal static partial int ShowCursor([MarshalAs(UnmanagedType.U1)] bool show);
    //                                                                  ~~~~ KHI001: Parameter 'show'
    //                                                                       of 'ShowCursor' does not
    //                                                                       follow the Win32 bool
    //                                                                       convention; expected
    //                                                                       [MarshalAs(UnmanagedType.Bool)]
}
```

## Fix

```csharp
[LibraryImport(nameof(SDL3), EntryPoint = "SDL_HasClipboardText")]
[return: MarshalAs(UnmanagedType.U1)]
internal static partial bool HasClipboardText();

[LibraryImport(nameof(SDL3), EntryPoint = "SDL_SetGamepadEventsEnabled")]
internal static partial void SetGamepadEventsEnabled([MarshalAs(UnmanagedType.U1)] bool enabled);
```

## Not reported

- Anything outside `Interop/SDL` and `Interop/Win32`.
- The generated implementing half of a `[LibraryImport]` partial method. Only
  the hand-written declaration is reported, because it is the one that can be
  fixed.

## Suppressing

Win32 also has `BOOLEAN`, a 1-byte type used by a handful of APIs. A binding
against one of those is a real exception and is suppressed where it happens,
with the native signature in the justification:

```csharp
[SuppressMessage("Interop", "KHI001", Justification = "RtlGenRandom returns BOOLEAN (1 byte), not BOOL.")]
```

Nothing else is a valid reason to suppress this rule.
