# KHI012: non-copyable value used outside its using

| Item     | Value                                |
| :------- | :----------------------------------- |
| Category | Interop                              |
| Severity | Error                                |
| Analyzer | `KappaDuck.Khaos.Internal.Analyzers` |

## Cause

A value of a type marked `[NonCopyable]`, such as `OwnedBuffer<T>`, is used in
a way that breaks its single ownership. Three uses are reported:

- **No using owns it.** A call or a `new` that creates the value is neither the
  initializer of a `using` nor returned: a temporary read on the spot, a plain
  local, an argument.
- **It is copied.** A variable that holds it is read for anything else than its
  members: another local, an argument passed by value, a `return` of a local
  that a `using` already owns.
- **It is disposed by hand.** `Dispose()` is called on a variable whose `using`
  already disposes it.

The rule looks at the whole framework, not only at `Interop/`: the wrappers in
`Interop/SDL` hand the value to the code that reads it.

## Why

`OwnedBuffer<T>` owns memory that SDL allocated and that only `SDL_free`
releases ([SDL_GetKeyboards], [SDL_free]). It frees that memory in `Dispose`, so
it has to be disposed exactly once:

- a value no `using` owns is never disposed, and the memory leaks;
- a copy holds the same pointer, and the second `Dispose` frees it again;
- a `Dispose()` by hand is followed by the one the `using` adds at the end of
  its scope.

The compiler cannot refuse a copy of a struct, and a `ref struct` does not
change that. It does keep the elements from outliving the buffer:
`OwnedBuffer<T>.Span` is marked `[UnscopedRef]` and builds its span from the
buffer passed by `in`, so the span cannot leave the block of the `using`
([ref safe context], [UnscopedRef]). This rule closes what remains, so the
`using` stays the one owner.

The attribute is named after the convention of the Roslyn analyzers (`RS0042`,
[Do not copy value]), which would also find the copies. KHI012 reports them
together with the two other cases, so no second analyzer is needed.

## Reported

```csharp
namespace KappaDuck.Khaos.Input;

internal static class Keyboards
{
    internal static int Count() => SDL3.GetKeyboards().Span.Length;
    //                             ~~~~~~~~~~~~~~~~~~~~ KHI012: This 'OwnedBuffer<uint>' has no using
    //                                                  to own it; declare it with using, or return it
    //                                                  to the caller
}
```

```csharp
using OwnedBuffer<uint> keyboards = SDL3.GetKeyboards();
using OwnedBuffer<uint> copy = keyboards;
//                             ~~~~~~~~~ KHI012: 'keyboards' is copied; read it through its members,
//                                       or pass it by in

keyboards.Dispose();
// ~~~~~~~~~~~~~~~~ KHI012: 'keyboards' is disposed by hand; its using already disposes it
```

## Fix

Give the value its `using`, and read it through its members:

```csharp
internal static int Count()
{
    using OwnedBuffer<uint> keyboards = SDL3.GetKeyboards();
    return keyboards.Span.Length;
}
```

A helper that only reads takes the value by `in`, which passes a reference
instead of a copy:

```csharp
private static int Count(in OwnedBuffer<uint> keyboards) => keyboards.Span.Length;
```

A wrapper that creates the value returns it right away, and the caller gives it
its `using`:

```csharp
internal static OwnedBuffer<uint> GetKeyboards()
{
    // SAFETY: …
    unsafe
    {
        uint* keyboards = ThrowIfNull(NativeGetKeyboards(out int count));
        return new OwnedBuffer<uint>(keyboards, count);
    }
}
```

## Not reported

- **The value read through a member**: `keyboards.Span`, `foreach`, a method
  other than `Dispose`.
- **The value passed by `in` or `ref`.**
- **A creation that initializes a `using`** (declaration or statement) **or is
  returned**, even inside an `unsafe` expression.
- **`nameof(keyboards)`.**
- **A type without `[NonCopyable]`**, or with an attribute of that name declared
  outside `KappaDuck.Khaos.Interop`.

## Suppressing

Never. A copy that has to happen means the type should not be `[NonCopyable]`.
