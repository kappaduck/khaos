# KHI009: native import outside an interop area

| Item     | Value                                |
| :------- | :----------------------------------- |
| Category | Interop                              |
| Severity | Error                                |
| Analyzer | `KappaDuck.Khaos.Internal.Analyzers` |

## Cause

A method marked `[LibraryImport]` lives outside `Interop/SDL` and
`Interop/Win32`: in another part of the framework, at the root of `Interop`, in
`Interop/Browser`, or in a namespace that only ends in `Interop`.

## Why

Every rule on native bindings takes its conventions from the area a binding
lives in: the `bool` width ([KHI001](khi001.md)), the explicit `EntryPoint`
([KHI003](khi003.md)), the library of the area ([KHI006](khi006.md)). A binding
outside an area has none, so none of them checks it, and it reaches native code
unguarded.

## Reported

```csharp
namespace KappaDuck.Khaos.Windowing;

internal static partial class Native
{
    [LibraryImport("SDL3", EntryPoint = "SDL_Quit")]
    internal static partial void Quit();
    //                           ~~~~ KHI009: 'Quit' imports a native function outside
    //                                Interop/SDL and Interop/Win32; move it to the area of its library
}
```

## Fix

Move the binding to the area its library belongs to, into the file matching the
header that declares it, and call it from there.

```csharp
namespace KappaDuck.Khaos.Interop.SDL;

internal static partial class SDL3
{
    [LibraryImport(nameof(SDL3), EntryPoint = "SDL_Quit")]
    internal static partial void Quit();
}
```

## Not reported

- **A `[LibraryImport]` in `Interop/SDL` or `Interop/Win32`**, at any depth
  (`Interop/SDL/Primitives`).
- **The generated implementing half of a partial method.** Its `__PInvoke` is a
  local function, and only the hand-written declaration is reported.

## Suppressing

Never. A binding outside an area is in the wrong folder.
