# KHI005: type in Interop is not internal

| Item     | Value                                |
| :------- | :----------------------------------- |
| Category | Interop                              |
| Severity | Error                                |
| Analyzer | `KappaDuck.Khaos.Internal.Analyzers` |

## Cause

A type declared anywhere in `Interop/` is visible outside the assembly: in an
area such as `Interop/SDL`, `Interop/Win32` or `Interop/Browser`, or at the root,
next to shared types such as `UntypedBecauseAttribute`.

Visibility is effective, not declared: a `public` type nested in an `internal`
one never leaves the assembly and is not reported. A `protected` or
`protected internal` type nested in a `public` one does leave it, since any
derived class in another assembly can see it.

## Why

This is the cheapest rule in the set and it carries the whole boundary.

Once every interop type is `internal`, the compiler enforces the rest by itself.
A public signature that mentions one fails with an accessibility error CS0053
and its neighbours before any analyzer runs. There is no need to walk return
types, parameters, generic arguments or array elements looking for leaks,
because the language already refuses them.

That is why the rule guards the declaration rather than the signatures. It stops
the leak at the only place it can start.

## Reported

```csharp
namespace KappaDuck.Khaos.Interop.SDL.Primitives;

public readonly struct SDL_Window;
//                     ~~~~~~~~~~ KHI005: 'SDL_Window' is visible outside the assembly;
//                                every type in Interop is internal
```

```csharp
namespace KappaDuck.Khaos.Interop;

public sealed class UntypedBecauseAttribute(string reason) : Attribute;
//                  ~~~~~~~~~~~~~~~~~~~~~~~ KHI005: 'UntypedBecauseAttribute' is visible outside
//                                          the assembly; every type in Interop is internal
```

## Fix

```csharp
internal readonly struct SDL_Window;
```

## Not reported

- **An `internal`, `private`, `private protected` or `file` type.**
- **A `public` type nested inside an `internal` one.**
- **An `extension` block.** It is not a type anyone can name; the class that
  holds it is reported instead.
- **Anything outside `KappaDuck.Khaos.Interop`**, including a namespace that
  only ends in `Interop`, such as `KappaDuck.Khaos.Windowing.Interop`. A native
  handle deliberately exposed for third-party interop lives in the module that
  owns it, not in the interop layer.

## Suppressing

Never. A type that has to be seen from outside does not belong in `Interop/`;
move it, or wrap it.
