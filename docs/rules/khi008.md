# KHI008: raw pointer on the public surface

| Item | Value |
| :-- | :-- |
| Category | Interop |
| Severity | Error |
| Analyzer | `KappaDuck.Khaos.Internal.Analyzers` |

## Cause

A method, property or field that is visible outside the assembly has a pointer
or a function pointer in its signature. Unlike the other rules, this one looks
at the whole framework, not only at `Interop/`: the leak happens where the
public surface is written.

## Why

[KHI005](khi005.md) keeps every interop type internal, and the compiler then
refuses any public signature that mentions one. Two shapes get through that net,
because every part of them is a public type:

```csharp
public unsafe void* Pixels { get; }
public unsafe delegate* unmanaged<int, void> Callback;
```

This rule closes them. A game should never hold a pointer that Khaos owns: the
lifetime is not theirs, and nothing stops them from using it after the renderer
is gone.

Because KHI005 holds, a pointer cannot hide inside a generic argument here so
this rule stays a direct check rather than a recursive walk. If KHI005 is ever
dropped, this one has to grow.

## Reported

```csharp
namespace KappaDuck.Khaos.Windowing;

public sealed unsafe class Window
{
    public void* Handle { get; }
    //           ~~~~~~ KHI008: 'Window.Handle' exposes a raw pointer;
    //                  the pointer stays behind the wrapper
}
```

## Fix

Keep the pointer in a private field and expose what the caller actually needs.
When the caller genuinely needs the native handle such as an overlay attaching to the
window, a video player then expose it as an `nint` and let them cast it.

```csharp
public sealed unsafe class Window
{
    private SDL_Window* _window;

    public nint Handle => (nint)_window;
}
```

## Not reported

- **`nint`.** It is not a pointer. Exposing a native handle that way is a
  deliberate decision, guarded by the architecture test and its exception list.
- **A member that does not leave the assembly**, including a `public` member of
  an `internal` type.
- **A property accessor.** The property is reported once, not three times.

## Suppressing

Only for a handle the framework means to hand out, and only where the
architecture test already lists it as an exception.
