# Breakout

Break every brick with a ball and a paddle.

<iframe src="/demo/Breakout/play/" title="Breakout, running in the browser" width="960" height="540" style="width: 100%; height: auto; aspect-ratio: 16 / 9; border: 0;" allow="fullscreen; gamepad; autoplay"></iframe>

## What it shows

- Sprites drawn and moved every frame
- Collisions between the ball, the paddle and the bricks
- Sound effects
- A score drawn as text

## Run it

```bash
dotnet run --project demo/Breakout/Breakout.Desktop
dotnet run --project demo/Breakout/Breakout.Web
```
